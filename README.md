# Atık Su Damıtma Ünitesi

Ev içinde oluşan gri ve siyah atık suyu damıtarak içilebilir suya çeviren, ısı pompası destekli mekanik buhar sıkıştırmalı (MVC) bir arıtma ünitesinin kavramsal tasarımı.

- `index.html`: interaktif 3D model (döndürme, parça bilgisi, akış animasyonu)
- `rapor.html`: teknik rapor

Çalışma noktası: 125 °C / 2,3 bar(a). Değerler yaklaşık mühendislik tahminleridir.
